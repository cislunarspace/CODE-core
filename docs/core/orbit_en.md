# Orbit Data: Orbit and OrbitFamily

> **File**: `e2m2e/core/orbit.py`

`Orbit` stores the state sequence and attributes of a single orbit (period, Jacobi constant, stability). `OrbitFamily` manages a family of orbits, typically generated by continuation algorithms.

## How to Create an Orbit Object

Usually you don't need to create one manually — the return values from `DifferentialCorrection.iterate_correction()` and `Dynamics.propagate()` are already `Orbit` objects.

Manual creation:

```python
import numpy as np
from e2m2e.core import CR3BP_System, Orbit

system = CR3BP_System.from_known_system("earth_moon")
states = np.array([[0.8, 0, 0, 0, 0.5, 0], ...])  # [n, 6]
times = np.array([0.0, 0.01, 0.02, ...])

orbit = Orbit(states=states, times=times, system=system)
```

Basic attributes (period, amplitude, Jacobi constant) are computed automatically upon creation.

## How to Analyze Orbit Properties

### Period and Amplitude

```python
print(f"Period: {orbit.period:.4f}")
print(f"x amplitude: {orbit.get_amplitude('x'):.6f}")
print(f"y amplitude: {orbit.get_amplitude('y'):.6f}")
```

### Stability Analysis

```python
from e2m2e.core import CR3BP_Dynamics

dynamics = CR3BP_Dynamics(system)

# Compute the Monodromy matrix (STM over one period)
orbit.compute_monodromy_matrix(dynamics)

# Compute Floquet multipliers and stability
stability = orbit.compute_stability(dynamics)
print(f"Stability: {stability['type']}")
print(f"Lyapunov exponents: {stability['lyapunov_exponents']}")
```

-> See [Stability Analysis](../algorithms/stability_en.md)

## How to Save and Load Orbits

### Single Orbit

```python
orbit.save_to_file("output/my_orbit.json")
loaded = Orbit.load_from_file("output/my_orbit.json", system=system)
```

### Orbit Family

```python
# Save (typically called directly on the OrbitFamily returned by Continuation)
family.save_to_file("output/dro_family.json")

# Load
from e2m2e.core.orbit import OrbitFamily
family = OrbitFamily.load_from_file("output/dro_family.json", system=system)
```

The JSON format contains the complete state sequence and metadata, and can be reused across sessions.

## How to Manage Orbit Families

`OrbitFamily` is typically generated automatically by the [Continuation](../algorithms/continuation_en.md) algorithm. Manual construction:

```python
from e2m2e.core.orbit import OrbitFamily

family = OrbitFamily(orbits=[orbit1, orbit2, orbit3], family_type="DRO", system=system)

# Access
print(f"Number of orbits: {len(family)}")
print(f"Jacobi constant range: {family.get_jacobi_constants()}")

# Iterate
for orbit in family:
    print(orbit.period)
```

-> For continuation generation of orbit families, see [Orbit Family Continuation](../algorithms/continuation_en.md)
-> For orbit family visualization, see [Visualization Guide](../guides/visualization-guide_en.md)

## API Quick Reference

### Orbit

| Method | Description |
|--------|-------------|
| `get_period()` | Get the orbit period |
| `get_amplitude(direction)` | Get amplitude in the specified direction ("x" / "y" / "z") |
| `compute_monodromy_matrix(dynamics)` | Compute the Monodromy matrix |
| `compute_stability(dynamics)` | Compute Floquet stability |
| `save_to_file(filename)` | Save to JSON |
| `load_from_file(filename, system)` | Load from JSON |
| `copy()` | Deep copy |

### OrbitFamily

| Method | Description |
|--------|-------------|
| `add_orbit(orbit)` | Add an orbit |
| `get_states()` / `.states` | Initial states of all orbits (n, 6) |
| `get_periods()` / `.periods` | Periods of all orbits |
| `get_jacobi_constants()` | Jacobi constants of all orbits |
| `save_to_file(filename)` | Save to JSON |
| `load_from_file(filename, system)` | Load from JSON |

For the full API documentation, see [API Reference](../reference/api-reference_en.md).
