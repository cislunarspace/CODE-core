# ADR 0063: 二维不变环面的频闪构造（最小口径第一阶段）

**状态**：已采纳（已实现，第一阶段）
**日期**：2026-10-31
**相关 issue**：#842
**相关**：ADR 0013（按定义验收）、ADR 0055（验收 oracle 类别）、ADR 0060（共享 PAL 内核）、CONTEXT.md 拟周期不变环面术语组

## 背景

#842 按最小口径重开不变环面构造（复核记录见 `.out-of-scope/invariant-torus-qpit.md`）。设计压测定案（见 #842 的 agent brief 修订）：网格采样加 DFT 旋转算子、旋转数耦合进牛顿系统、中心乘子对内部自动选取、旋转数弧度口径、algorithm/torus 新子包、Python 全程、共振与包络如实报告、振幅取法向最大偏离、默认测试用仓内种子小网格。

## 决策

1. **频闪口径与固定频闪周期**。求解以种子周期 T 为频闪周期的离散映射的不变闭曲线 P_T(C(φ)) = C(φ+ρ)。未知量为相位网格上的曲线采样（N 点带限）与旋转数 ρ；频闪周期不作为未知量。曾把频闪周期 τ 也作为未知量：它引入轨道族方向的连续解族（邻近周期轨道的环面也是解）与强耦合的病态列，构造无法收敛，已回退到固定周期口径（与报告人验证的频闪口径一致）。
2. **过采样配点**。不变性条件在 2N 个相位上求值（配点数两倍于未知采样点），超定最小二乘把网格全频段中的高次模钉住，防止数值解在无物理内容的模式上漂移。
3. **方程组与规范**。列 = 6N（曲线采样）+ 1（ρ）；行 = 12N 不变性 + 振幅钉扎 + 慢相位参数化规范（一阶正弦分量过零）+ 快相位切片规范（曲线沿流方向的平均偏离为零）。切片对称来自流与自身可交换：整条曲线沿流推进任意小量后仍是解。平面种子的两个单位模对使环面族成为两参数族（面内与法向振幅），钉住法向振幅后仍有面内方向的连续解族，本阶段不处理（见决策 8）。
4. **带限插值**。网格到配点、φ+ρ 平移及其导数统一用 fft 序模式集（对称重建）。自然序 0 到 N−1 的 Dirichlet 和只在网格相位上与对称集重合，离网格相位差一个相位卷绕；曾因此在传播喂入相位卷绕的状态、种子残差出现 O(A) 假象，修复后回到物理的 O(A²)。
5. **求解器**。信赖域阻尼最小二乘：SVD 分解、Levenberg 阻尼、步长硬约束（初值取振幅一半）、按实际下降与线性预测的增益比自适应。收敛判据看全残差（含钉扎与规范行）：只看不变性行会在振幅未达目标时误报收敛（振幅阶梯曾因此空转）。
6. **振幅同伦**。近月空间映射的二阶曲率大（Halo 与 DRO 邻域等效 |D²P| 约 2e3），线性种子在 1e-3 以上振幅已出牛顿二次收敛域。构造内部从 1e-4 起沿 1.3 倍阶梯爬升，逐级以已收敛解热启动；级差按标定取 1.3（2.5 倍级差在 2.5e-4 附近撞残差地板）。
7. **实现落点**。`e2m2e/algorithm/torus/`（construction 加 diagnostics），Python 全程，传播走 Rust with_stm 路径。延拓机器（第二阶段）与共享 PAL 内核同口径但自持实现，不改动 pal_core；Rust 下沉的触发条件是工具面或目录消费出现。
8. **限制如实报告**。可达振幅包络实测为 1e-4 到约 2.9e-4（月球距离单位）：更大振幅处残差停在 1e-6 量级地板，钉扎无法满足，构造以状态三元组如实报告不收敛。平面 DRO 的双中心对形态即使在小振幅也出现同类地板（面内振幅方向未规范）。强双曲种子（L2 Halo 面内对 1206/8e-4）的长弧距离读数由双曲放大主导，不反映曲线失真。三类问题的治理（面内振幅规范或中心流形约化、方程与变量的尺度均衡、以延拓参数替代钉扎）归第二阶段振幅延拓。
9. **测试**。默认套件用仓内 L2 Halo 种子加 16 点网格（包络内振幅），合成谱测试覆盖中心对选取的三条判别路径；超出包络的目标断言如实报告状态三元组。论文对照值（36.5 天、58.3 天、0.031）只进 docstring。

## 数值证据

L2 Halo（`design_halo(2, 3000 km)`，周期 3.415 TU，中心对辐角 0.0429825 rad）：振幅 5e-5 处求解系统残差 5.3e-12，ρ 与 α 差 6e-8；振幅 1.5e-4 处不变性残差 6.4e-11，振幅命中目标，ρ = 0.0429858（差 3.3e-6，符号与量级符合二次扭转）。振幅同伦 1.3 倍级差实测爬到约 2.9e-4 后停在残差地板 5.8e-7。DRO 种子（x0=0.7919，双中心对）在 1e-4 振幅同样出现 2e-6 量级地板。
