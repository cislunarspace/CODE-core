# ADR 0063: 二维不变环面的频闪构造（最小口径第一阶段）

**状态**：已采纳（已实现，第一阶段）
**日期**：2026-10-31
**相关 issue**：#842
**相关**：ADR 0013（按定义验收）、ADR 0055（验收 oracle 类别）、ADR 0060（共享 PAL 内核）、CONTEXT.md 拟周期不变环面术语组

## 背景

#842 按最小口径重开不变环面构造（复核记录见 `.out-of-scope/invariant-torus-qpit.md`）。设计压测定案（见 #842 的 agent brief 修订）：网格采样加 DFT 旋转算子、旋转数耦合进牛顿系统、中心乘子对内部自动选取、旋转数弧度口径、algorithm/torus 新子包、Python 全程、共振与包络如实报告、振幅取法向最大偏离、默认测试用仓内种子小网格。

## 决策

1. **频闪口径与固定频闪周期**。求解以种子周期 T 为频闪周期的离散映射的不变闭曲线 P_T(C(φ)) = C(φ+ρ)。未知量为相位网格上的曲线采样（N 点带限）与旋转数 ρ。频闪周期不作为未知量。曾把频闪周期 τ 也作为未知量：它引入轨道族方向的连续解族（邻近周期轨道的环面也是解）与强耦合的病态列，构造无法收敛，已回退到固定周期口径（与报告人验证的频闪口径一致）。
2. **过采样配点**。不变性条件在 2N 个相位上求值（配点数两倍于未知采样点），超定最小二乘把网格全频段中的高次模钉住，防止数值解在无物理内容的模式上漂移。
3. **方程组与规范**。列 = 6N（曲线采样）+ 1（ρ）。行 = 12N 不变性 + 振幅钉扎 + 慢相位参数化规范（一阶正弦分量过零）+ 快相位切片规范（曲线沿流方向的平均偏离为零）。切片对称来自流与自身可交换：整条曲线沿流推进任意小量后仍是解。平面种子的两个单位模对使环面族成为两参数族（面内与法向振幅），钉住法向振幅后仍有面内方向的连续解族，本阶段不处理（见决策 8）。
4. **带限插值与奇数网格**。网格到配点、φ+ρ 平移及其导数统一用 fft 序模式集（对称重建）。自然序 0 到 N−1 的 Dirichlet 和只在网格相位上与对称集重合，离网格相位差一个相位卷绕。曾因此在传播喂入相位卷绕的状态、种子残差出现 O(A) 假象，修复后回到物理的 O(A²)。网格点数取奇数：偶数网格的 Nyquist 模（k = N/2）在实带限表示里没有共轭搭档，不可一致旋转，数值解把残余垃圾堆进该模后旋转不一致性成为残差地板的一部分。
5. **求解器**。高斯牛顿加 Armijo 回溯线搜索：SVD 分解滤除相对奇异值低于 1e-12 的方向，步长沿纯高斯牛顿方向折半回溯。双中心对种子另按未规范方向数（非平凡单位模对数减一）显式丢弃最小的相应数量个奇异方向。曾用 Levenberg 阻尼（含信赖域与增益比自适应）：阻尼先削平坦方向的分量，而远离解时需要的修正恰恰整体住在平坦方向上，按奇异值阻尼得到方向错乱的步，实测在振幅阶梯上撞 1e-6 量级残差地板。t 缩放保持方向只收步长后同一阶梯直接爬过。不丢弃未规范方向时，双中心对种子面内振幅方向的数值奇异值约 3e-6、按 σ/σ² 放大把步长爆到该方向上（ρ 从 1.4159 漂到 1.3938），丢弃后漂移止住。收敛判据看全残差（含钉扎与规范行）：只看不变性行会在振幅未达目标时误报收敛（振幅阶梯曾因此空转）。
6. **振幅同伦与网格匹配**。近月空间映射的二阶曲率大（Halo 与 DRO 邻域等效 |D²P| 约 2e3），线性种子在 1e-3 以上振幅已出牛顿二次收敛域。构造内部从 1e-4 起沿 1.25 倍阶梯爬升，逐级以已收敛解热启动（1.6 倍级差在 0.02 附近失去收敛域）。网格密度随振幅放大：环面截面的高次谐波按约 0.17 至 0.25 的比率逐模衰减，带宽不足时残差停在截断地板（17 点网格在 A 约 1e-2 处带边模含量 2.5e-7，残差地板抬到 1e-9 量级，与截断误差吻合）。L2 Halo 标定：17 点网格覆盖到 1e-2 量级，33 点覆盖论文法向振幅 0.031。
7. **实现落点**。`e2m2e/algorithm/torus/`（construction 加 diagnostics），Python 全程，传播走 Rust with_stm 路径。延拓机器（第二阶段）与共享 PAL 内核同口径但自持实现，不改动 pal_core。Rust 下沉的触发条件是工具面或目录消费出现。
8. **限制如实报告**。单中心对种子（Halo 形态）按网格与振幅匹配的口径实测：17 点网格到 1e-2 量级（边缘级的残差地板抬到 1e-9 量级，为频带截断误差），33 点网格到论文法向振幅 0.031（残差 9.4e-11、共轭残差 2.0e-9），不匹配的组合（大振幅配稀网格、或小振幅配密网格引入带边弱方向）如实报不收敛。平面 DRO 的双中心对形态丢弃未规范方向后 ρ 稳住在法向对辐角，但振幅塌到 6.6e-5、残差停在 1e-5，被奴役的面内响应与自由分量同为 k=1 模、不可按模式内容分离，需要面内振幅规范或中心流形参数化。强双曲种子（L2 Halo 面内对 1206/8e-4）的长弧距离读数由双曲放大主导，不反映曲线失真。这些治理归第二阶段振幅延拓。
9. **测试**。默认套件用仓内 L2 Halo 种子加 17 点网格（包络内振幅），合成谱测试覆盖中心对选取的三条判别路径。超出包络的目标断言如实报告状态三元组。论文对照值（36.5 天、58.3 天、0.031）只进 docstring。

## 数值证据

L2 Halo（`design_halo(2, 3000 km)`，周期 3.415 TU，中心对辐角 0.0429825 rad）：振幅 5e-5 处求解系统残差 5.3e-12，ρ 与 α 差 6e-8。振幅 1.5e-4 处不变性残差 6.4e-11，振幅命中目标，ρ = 0.0429858（差 3.3e-6，符合二次扭转）。振幅 0.001（17 点）残差 5.2e-10、共轭残差 2.1e-7。振幅 0.011（17 点）在 8.7e-3 处停滞，残差 2.5e-9 停在 17 点频带的截断地板（带边模含量 2.5e-7）。振幅 0.031（33 点、1.25 倍级差）残差 9.4e-11、共轭残差 2.0e-9、振幅命中、ρ = 0.1045、第二周期 891 天。此前 Levenberg 阻尼形态的阶梯只能到 3.7e-4 附近。DRO 种子（x0=0.7919，双中心对）丢弃未规范方向后残差仍停在 1e-5（振幅塌缩，带边 k=8 模含量 3e-4）。复算入口 `scripts/calibrate_invariant_torus.py`。
