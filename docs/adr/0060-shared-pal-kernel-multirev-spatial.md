# ADR 0060: 共享全周期 PAL 数值内核与多圈闭合、三维非对称实例

**状态**：已采纳（已实现）
**日期**：2026-10-23
**相关 issue**：#820
**相关**：ADR 0028（平面三角平动点全周期 PAL）、ADR 0002（Rust 数值内核）、ADR 0055（验收 oracle 类别）、#687（稳定性分析删除边界）

## 背景

ADR 0028 立案平面全周期 PAL 时预留了条款：仅有一个非对称平面适配器时不引入通用抽象，当第二个真实三维全周期适配器出现时抽取共享 PAL 数值内核。issue #820 带来了这个第二适配器（butterfly 类非对称三维分支）以及一个多圈闭合形状（月心 DRO 族上的五周期共振分支），并附三次普通牛顿打法的失败记录：近退化 pitchfork 的收敛盆把有限振幅种子全部吸回平凡叶。

拆解既有平面内核（943 行）可见，真正平面特化的只有三处：分量选择常量（x、y、vx、vy）、五维未知量与六维状态的互转、缩放向量。传播与残差求值、相位规范、SVD 切向量、阻尼最小二乘牛顿、线搜索、步长收缩与秩诊断全部与维数无关。三维非对称实例需要的正是同一套机器，只是未知量从五维变七维、分量选择从四个变六个。

标定过程澄清了一个数值事实：单值矩阵恒有的平凡乘子对在数值上分裂为 1±1e-6 量级的近实对，其五次幂即 #820 报告的临界乘子 1.0000214，不是共振乘子本身。共振判据因此必须显式跟踪非平凡复数对（辐角二分定位 2π/n），不能按最接近 1 选取。

## 决策

1. **抽取共享内核 `pal_core`（e2m2e-integrators 内）**。问题形状由 `PalShape` 描述：状态分量选择、q 各维缩放、闭合圈数 n、消息前缀。实现取动态维度（nalgebra DVector 与 DMatrix）：平面（四分量、五维 q）与三维非对称（六分量、七维 q）是同一内核的两个实例化，全仓只保留一份 SVD 牛顿 PAL 循环。
2. **闭合推广为 n 圈**。闭合残差在 n·T 上求值（雅可比周期列乘 n），成员闭合周期报告 n·T，n 等于 1 即 ADR 0028 原形式。`planar_full_period_pal_py` 增可选关键字 `n_revolutions`（默认 1，既有调用与数值行为不变，由 SPO 与 LPO 回归钉住），算法层平面适配器对应增 `closure_revolutions` 形状参数。
3. **三维非对称实例**。新增 `spatial_full_period_pal_py` 与 `SpatialPalRustResult`：六分量闭合、相位条件与弧长条件与平面形态同口径，不施加对称性或平面约束。ABI 升至 v30。三维内核由沿 L1 halo 族真实行走验证（成员闭合 1e-13 量级）。butterfly 分支的 halo 族乘子扫描定位未在本次完成，留作后续工单。
4. **分岔起链是算法层内部自含能力**（`algorithm/family/resonant_branch`）。三段式：沿平凡族二分定位共振成员（非平凡复数对辐角命中 360/n 度），沿共振平面（特征向量实部与虚部）做 deflection 并以固定 x0 的 n 圈闭合阻尼最小二乘精化，组合穷举后取分支振幅最大者为种子，交 PAL 行走。非平凡判据按圈数分派：n 大于 1 用单圈闭合偏差（平凡族成员单圈即闭合），n 等于 1 用对称破缺分量 y0 与 vx0。共振乘子偏差超过门限时显式拒绝起链，不静默落回平凡族。该能力不进接口层，不构成稳定性或分岔分析工具（#687 的边界）。
5. **保持不动**。XZ 对称半周期内核与 halo 链路（ADR 0028 明文保留）、三处延拓编排不合并（#747 与 #748）、接口层零改动：butterfly 不进 `orbit_family_generation` 工具面，`OrbitFamilyType.BUTTERFLY` 维持待实现占位，不新增公开请求模型。
6. **验收全定义性**（ADR 0055）：闭合无穷范数不超过 1e-8、Jacobi 漂移检查、平面约束、单圈不闭合、n 等于 1 时既有回归全部通过。文献振幅量级（Zhang 2022 Fig. 12 的 z 到 −0.2）只进 docstring 与标定脚本的人工对照，不进断言。

## 数值证据

库内标定（`scripts/calibrate_dro_5rev_resonance.py`）：五周期共振成员 x0=0.900664、vy0=0.477498、T=1.263943 TU，共振乘子辐角 72.0000 度，五次幂乘子与 1 的偏差 1.9e-06。起链后沿分岔支行走（步长 0.005）：成员闭合残差最大 1.1e-9，单圈闭合偏差从 8.9e-3 增长到 2.4e-2（八成员），z 与 vz 恒为零。反方向为单侧分支，一步即停滞并以状态三元组如实报告。与 #820 报告值（x 约 0.879、vy 约 0.4705、乘子 1.0000214）的差异：报告值出自报告人自有 scipy 实现的族参数化，且其临界乘子是平凡对数值分裂的五次幂，库内值是定义性复算结果。

## 后果

- 新的问题形状（其他圈数、其他平面或三维族）以 `PalShape` 实例加入，不再复制内核。每加一族的成本回到算法层适配器级别。
- 平面内核从静态维度改为动态维度，代数层分配开销相对传播成本可忽略，行为由既有回归与 crate 单元测试钉住。
- butterfly 分支生成需要 halo 族乘子扫描的精化（平凡对分裂判别、更深 NRHO 段行走），共享内核与起链入口已就绪，后续工单只补定位侧。
- `make check` 与受影响测试全部通过。Rust 全量串行测试中 `family_generation::tests::ro_seed_period_is_exactly_commensurate` 在本机为预先存在的失败（master 同样失败），与本决策无关。

## 修订（2026-10-26，#821）：周期倍化两族进 `orbit_family_generation` 工具面

### 背景

决策 5 写作时（#820）只有共享内核与起链入口，halo 族乘子扫描定位未完成，butterfly 类分支没有接口面可言。#821 落地了定位侧（Broucke 图 f = 2 + β − 2α 归零、约化雅可比对称扇区最小奇异值归零、单值矩阵乘子负一三条判据在同一成员上一致）与两条子族的生成入口，工具面问题重新提出。

### 决策

决策 5 的“butterfly 不进 `orbit_family_generation` 工具面”就两条已实现子族修订：`figure_eight`（8 字形族，分岔 x0 约 1.0118）与 `ring`（0 形族，分岔 x0 约 1.1094）作为既有 `orbit_family_generation` 工具的两个新 `orbit_type` 进入工具面（`FamilyGenerationRequest` 扩 FIGURE_EIGHT/RING 与族参数窗口字段，不新增工具）。准入按 ADR 0043 决策 6 第一款判定：族生成本就是任务级能力，此处只是既有任务级工具的 orbit_type 闭值集扩展，族名闭值经 ADR 0044 的 `RECORD_ORBIT_FAMILIES` 登记出库。`OrbitFamilyType.BUTTERFLY` 占位维持不动。决策 5 的“接口层零改动”就本次扩请求字段作废：`FamilyGenerationRequest` 新增 FIGURE_EIGHT/RING 分支与族参数窗口，属于既有任务级工具的闭值集扩展，不新增工具。

### 后果

- 分岔定位与三判据仍是族生成的内部起链能力，不构成稳定性或分岔分析的接口面或算法层模块（#687 边界不变）。
- 0 形族成员每周期 2 次垂直加 2 次斜 y=0 穿越，实测分类为 halo/axial 标签而非 butterfly。分类学穿越判据不改，族名闭值与几何标签并存，期望集按实测口径登记，冲突只告警不失败（ADR 0042 决策 5）。
