# ADR 0062: LVLH 参考体选项与角动量符号约定

**状态**：已采纳（实现随 #834）
**日期**：2026-10-30
**相关 issue**：#834
**相关**：ADR 0007（动态轴状态注入，决策 5 与 6 经本篇修订）、ADR 0020（退化态显式失败）、ADR 0055（验收 oracle 类别）、#832（Floquet 模态）、#835（相对运动不设任务级工具）

## 背景

`LVLHAxes` 与相对运动层的 LVLH 转换都直接用传入状态自己的 r 与 v 构造轴向。状态在 CR3BP 会合系里，于是径向从地月质心量起，法向取质心会合角动量 r × v_syn。月球附近的相对运动文献常用另一种约定，径向从月球指向目标，法向取目标相对月球的角动量。两种约定在 2:1 DRO 上不是同一个坐标系。

实测 2:1 DRO（月心近侧穿越 -0.192 LU，周期 3.397136 TU，闭合差 4.5e-14）上，质心径向与月心径向的夹角在 t=0 为 180 度，周期内最小 4.14 度，随轨道演化在两者之间变化。issue 正文写的 3.5 度只在近月侧附近成立，远月侧接近反向。复现论文时调用方只能自己写十几行月心基构造，两种约定下转移燃耗相差约 15%。

角动量的符号事实比 issue 正文更细。记 h1 为质心会合角动量 (r × v_syn)_z，h2 为月心会合角动量 ((r - r_moon) × v_syn)_z，h3 为月心惯性角动量 ((r - r_moon) × (v_syn + ω × (r - r_moon)))_z，速度取相对月球的惯性值。同一条 2:1 DRO 上 h1 在 t/T 约 0.21 与 0.79 过零，h2 与 h3 全程为负。issue 正文报的惯性口径在 t/T 约 0.27 与 0.73 变号，与速度只取 v_syn + ω × r、没减掉月球自身惯性速度的写法给出的变号位置一致，该写法比 h3 多出 (r - r_moon) × (ω × r_moon) 一项，t=0 时约 -0.19，与 h2 同量级。issue 说的会合系符号恒定只对月心参考体成立。现有默认双质心 LVLH 在这条轨道上于 h1 过零处基矢翻转，属于既有缺陷。

论文对照取杨驰航等，航空学报 2023 年 44 卷 5 期 326563。论文 L 系的 z 轴就是 h2，速度分量用随动导数 v_L = Cᵀρ̇ + Ċᵀρ，与现有 `to_lvlh` 的速度变换一致。式(13) 的 e3(0) = (0, 0.5554, 0, 0.8316, 0, 0) 可用仓库的切向方向与月心基独立复算。

## 决策

1. 新增 `LVLHReference` 枚举，取值 BARYCENTER、PRIMARY、SECONDARY，放 `e2m2e/data/templates/enums.py`。枚举是数据，按 ADR 0011 归 data/templates，不在 coordinate 模块另立一份。现有 `ReferenceFrame` 的 BARYCENTRIC、PRIMARY_CENTERED、SECONDARY_CENTERED 描述坐标原点，不复用。

2. 坐标层新增两个共享函数。`reference_body_position(reference, mu)` 返回参考体在会合系的位置，双质心在原点，主天体在 (-μ, 0, 0)，次天体在 (1-μ, 0, 0)。`lvlh_basis(r_rel, v)` 由参考体相对位置与会合速度构造旋转矩阵，退化阈值集中在函数内，退化时抛 ValueError，异常信息含实测范数与阈值。

3. `LVLHAxes` 增加构造参数 `reference` 与 `mu`，`update(t, state)` 签名不变，内部先减参考体位置再调 `lvlh_basis`。`to_lvlh` 与 `from_lvlh` 各加关键字 `reference`，逐次显式传入，中心差分在 t±dt 两次求值沿用同一参考体。默认双质心，现有输出逐位不变。

4. 法向用会合速度，不用惯性相对速度。论文 L 系的 z 轴就是 h2，惯性口径与它在同一条 2:1 DRO 上都不变号，但基矢指向不同，实现只提供会合速度口径，惯性口径作为 docstring 中的约定说明记录。

5. 参考体只决定三根轴的方向，不改变相对状态自身的参考原点。`to_lvlh` 的输入仍是调用方给出的会合系相对状态。

6. 非双质心参考体的位置按 CR3BP 会合系常数计算，只适用于会合系状态。星历目标请保持双质心默认，本单不加运行时拦截，按文档边界处理。

7. 参考体选项收敛到 `LVLHAxes` 构造参数，取代 ADR 0007 决策 6 当年推迟的 `ObjectReferencedAxes` 设想。ADR 0007 在决策 6 加修订注说明这一变化。

8. 验收用两类测试。周期内 25 点采样固定 h1 的过零位置与 h2、h3 的符号。月心 LVLH 的切向基础解初值与论文式(13) 逐分量对照，容差 1e-3。

## 考虑过的替代方案

- 扩展 `DynamicAxes.update` 接收天体状态，沿用 ADR 0007 决策 6 的方向。CR3BP 的天体位置固定，proximity 层又没有天体状态对象，仍要由 μ 自己造一个，麻烦只是挪到调用点。
- 新建 `ObjectReferencedAxes` 子类。语义清楚，但 LVLH 基会出现第三份实现，而公式与退化阈值应只有一份。
- 月心法向用惯性相对速度。论文自己的 z 轴是 h2，两种口径在同一条 2:1 DRO 上都不变号，改用惯性相对速度只会让基矢偏离论文定义。
- 把 CR3BP 默认参考体改成月心。现有调用行为会变，本单改为可选，默认保持双质心。

## 数值证据

- 2:1 DRO：月心近侧穿越 -0.192 LU，周期 3.397136 TU，约 14.752 天，闭合差 4.5e-14。
- 25 点采样：h1 在索引 6 与 19 变号，对应 t/T 从 0.2083 到 0.25、从 0.75 到 0.7917 的两个区间。h2 全程为负，范围 [-0.1023, -0.0920]。h3 同样全程为负，范围 [-0.0652, -0.0216]，2001 点采样无变号。
- 两种径向的夹角：t=0 为 180 度，周期内最小 4.14 度。
- 论文对照：仓库切向方向 (0, 0.5316, 0, 0.6756, 0, 0)，经 `to_lvlh(reference=SECONDARY)` 得到 (5e-13, 0.555198, 0, 0.831719, -6e-12, 0)，与论文 (0, 0.5554, 0, 0.8316, 0, 0) 的最大分量残差 2.0e-4。

## 后果

- 默认双质心路径逐位不变，现有坐标轴、相对运动与 Floquet 测试不受影响。
- 大 DRO 的公里级编队几何可以显式选月心参考体，不必在调用方维护月心基。
- 双质心默认在 2:1 DRO 上的基矢翻转写进 docstring 与 ADR，调用方按需切换。
- proximity 层的退化态从产出 NaN 变为抛 ValueError，与 ADR 0020 的方向一致。
- 工具面不变。Facade、MCP、CLI 与 sidecar 不新增方法，相对运动仍只走进程内 import（#835）。
