# ADR 0055: 验收 oracle 类别化与文献数值边界——①–⑥ 断言、⑦ 仅注释

**状态**：已采纳（决策记录；断言实践随 #723/#724/#725/#727 实施链交付）
**日期**：2026-09-27
**相关 issue**：#722（本决策 issue）、#718（迁移总纲地图）、#723（行星际
MGA 连接器）、#724（SEP 功率模型与螺旋初猜）、#725（Sims-Flanagan conic
档）、#727（星历 n 体档）
**相关**：ADR 0013（验收策略——决策 2 的文献数值边界由本 ADR 细化，其文末
有修订注记，互指）、ADR 0021（测试功能类别）、ADR 0034（决策 6(a) 退化极限
锚定先例）、ADR 0037（时间预算与最小真实调用）、ADR 0041（定义性表值断言
先例）、ADR 0050（SF 双档保真度与 conic 内核契约）、ADR 0053（通用段框架
后置）、ADR 0054（MGA/SF 工具暴露）

## 背景

Issue #722 提出：#718 迁移总纲的四个切片（#723 / #724 / #725 / #727）按
已发表论文重实现 MALTO / Mystic / Copernicus 的核心算法，而仓库禁止把外部
软件运行时输出当 oracle——切片的验收基准用什么。issue 给出三个选项：

- **A. 闭式公式 + 守恒量为主，文献数值仅入注释**（推荐）；
- **B. 仅闭式公式 + 守恒量**；
- **C. A + 复现算例数值断言**（如 Sims & Flanagan 1999 算例）。

仓库既有实践已经分叉，边界从未明文：

- spatiography 直接断言论文 Table 1/2 与 §5 正文数值（`rel=1e-4`，并在用例
  内逐条内嵌复现陷阱注记；见 `tests/algorithm/spatiography/test_scales.py`、
  `test_resonances.py`，决策先例见 ADR 0041）——这属 ⑥ 类定义性数值。
- `tests/algorithm/transfer/test_lowthrust_shooting.py` 的
  `test_lowthrust_shooting_known_control_reproduction` 明确拒绝 SMART-1
  （200 天）、Conway LEO→GEO（199 天）文献算例，只用短弧已知控制复现验证
  机制——这是 ④ 类机制测试，⑦ 类结果性数值被弃用。
- ③ 类退化极限锚定已在用（ADR 0034 决策 6(a)：星历输入圆化/静止化后动力学
  逐项退化为 `Cr3bpSynodic`），④ 类机制测试也在用，但两类从未命名入册，
  新切片无从引用。

## 决策

1. **全仓 oracle 类别表（①–⑦）**：断言只用 ①–⑥；⑦ 类数值永不进 CI 断言。

   | 类别 | 名称 | 原理 | 仓内先例 |
   |---|---|---|---|
   | ① | 闭式公式 | 解析解即定义：正确实现自然满足 | 二体传播闭合、Hohmann Δv 与理论匹配（ADR 0013 决策 1） |
   | ② | 守恒量/不变量 | 守恒律与辛结构不随实现变 | Jacobi 守恒、STM det = 1（ADR 0013 决策 1） |
   | ③ | 退化极限锚定 | 参数退化到已验证实现的定义域，逐项一致 | ADR 0034 决策 6(a)（星历→CR3BP 圆化退化） |
   | ④ | 机制测试 | 合成已知可行输入，解算器应近乎立即收敛（残差 ≈ 0） | `test_lowthrust_shooting_known_control_reproduction` |
   | ⑤ | 文献公式 | 已发表公式与系数属领域公理，与实现无关 | Vallado、Richardson 系数（ADR 0013 决策 2） |
   | ⑥ | 定义性数值 | 论文采用的常数集、公式系数、可由 ⑤ 类公式复算的表值 | spatiography Table 1/2 表值（ADR 0041） |
   | ⑦ | 结果性数值 | 他人在其内核/离散/求解器设置下的仿真或优化输出 | 无（仅 docstring 人工对照） |

2. **⑥/⑦ 边界**：**定义性** = 论文采用的常数集、公式系数、可直接由 ⑤ 类
   公式复算的表值；**结果性** = 他人仿真或优化输出（例：ARM 螺旋
   ΔV ≈ 4.6 km/s、Sims & Flanagan 1999 算例收敛值）。⑥ 类可断言，但每个
   数值必须记录容差与复现陷阱（沿用 ADR 0041 的陷阱注记惯例）；⑦ 类禁入
   断言，因为对不上时无法区分己方 bug 与口径差（内核设置、离散方案、求解器
   均不可控）。

3. **⑦ 类登记纪律**：不建集中登记页。⑦ 类数值以论文引用（作者 年份 §节）
   加标注“非断言人工对照”的形式，写在相关模块或测试的 docstring 内，
   就近可查。

4. **容差纪律**：① ② 用研究级紧容差；③ 逐项一致并写明容差；④ 用残差 ≈ 0
   的收敛判据级容差；⑥ 逐值记录容差与陷阱注记。具体数值随各切片测试落定，
   本 ADR 只锁类别与方向。

5. **切片映射表**（各切片验收断言的 oracle 类别）：

   - **#723 MGA（patched-conic 借力链搜索）**
     - ① flyby 转角闭式 δ = 2asin(1/(1 + r_p v∞²/μ))；
     - ② 借力前后 |v∞| 等模守恒；
     - ① 日心能量改变 = 天体速度矢量叠加的解析关系；
     - ③ 借力强度趋于零时链退化为纯 Lambert 链（零退化极限）；
     - ② 若实现 Tisserand 筛选（#723 待决策 3），借力前后 Tisserand 参数不变；
     - ⑦ ARM 论文链的 ΔV 量级仅 docstring（非断言人工对照）。
   - **#724 SEP（功率模型与螺旋初猜）**
     - ① Edelbaum 共面圆-圆 ΔV = |v₁ − v₂| 及含倾角形式闭式；
     - ① 常推力时间/质量闭式 t = (m₀c/T)(1 − e^(−ΔV/c))；
     - ② ṁ = T/(Isp·g₀) 与上述闭式的时间/质量关系一致；
     - ⑤ 功率模型 P(r) = P₀(1AU/r)² − P_bus（论文模型定义）；
     - ⑥ 论文采用的推进参数集（P₀、Isp 等）作为场景输入引用；
     - ⑦ ARM 螺旋 ΔV ≈ 4.6 km/s 仅 docstring（非断言人工对照）。
   - **#725 Sims-Flanagan conic 档（五件套 + Rust 两项）**
     - ④ 机制测试：合成可行控制作初猜，残差 ≈ 0 立即收敛；
     - ② 匹配点连续性等式约束不变量；
     - ② 段可行域 |ΔVᵢ| ≤ a_max(r)/m·Δt；
     - ③ 零推力退化纯 conic（末态等于二体封闭解）；
     - ① ΔV sanity 带：**Hohmann（冲量下界）≤ ΔV_SF ≲ Edelbaum（连续上界
       参照）**——粗离散靠近 Hohmann 下界，细离散靠近 Edelbaum 上界；
     - Rust：① universal-variable 封闭解对照 f & g 系列闭式；② 解析 STM 的
       辛性 det(Φ) = 1；
     - ⑦ Sims & Flanagan 1999 算例收敛值仅 docstring（非断言人工对照）。
   - **#727 星历 n 体档**
     - ③ 圆化/静止退化极限下与 conic 档逐项一致（ADR 0034 决策 6(a) 先例）；
     - ② 同一 (t, state) 的星历档受力与 `compute_total_acceleration` 直接
       调用逐点一致。

6. **适用范围**：本表是全仓验收词汇表。后续新能力的验收口径直接引用类别
   编号，不再重新论证 oracle 政策。

## 理由

1. **B 否决**：Sims-Flanagan 整链收敛质量将无任何量级参照，ΔV sanity 带
   （冲量下界 + 连续上界参照）无从表达；③ 退化极限锚定与 ④ 机制测试两类
   既有实践在新政策下无家可归；且与 #727 已写验收口径（ADR 0034 决策 6(a)
   先例）直接冲突。
2. **C 否决**：复现算例数值取决于他人内核设置、离散与求解器，断言脆弱，
   对不上时分不清己方 bug 与口径差，违 ADR 0013 决策 2 的精神。
3. **“文献数值一律仅注释”否决**：那会使 spatiography 现存 Table 1/2 表值
   断言成为违例，改动面反而更大；把 ⑥ 与 ⑦ 切开即可保住该先例。
4. **类别化的代价是命名，收益是可引用**：③ ④ 两类已在实践里跑完整条决策
   链，命名入册后新切片不必重复论证 oracle 政策。

## 后果

- #723 / #724 / #725 / #727 的测试按决策 5 映射表写，具体容差随各切片落定。
- `AGENTS.md` 的 Testing 节同步本政策一句并指向本 ADR。
- ADR 0013 文末加修订注记，细化其决策 2 的文献数值边界，与本 ADR 互指。
- ⑦ 类数值永不进 CI 断言，仅以“非断言人工对照”标注存在于 docstring。
- 本 ADR 无代码行为变化；迁移切片的测试由 #723 / #724 / #725 / #727 交付，
  本决策 issue（#722）仅落决策记录。

## 备选方案

- **B：仅闭式公式 + 守恒量**：最严格，但 SF 整链收敛质量无量级参照，③ ④
  两类既有实践无归属，并与 #727 已写口径冲突；否决。
- **C：A + 复现算例数值断言**：把他人内核/离散/求解器设置下的输出升为验收
  基准；违 ADR 0013 决策 2；否决（#722 选项 C 的原形）。
- **严格 A 的字面版（文献数值一律仅注释）**：与 spatiography 现存表值断言
  冲突，需回改已实现切片；否决，改用本 ADR 的 ⑥/⑦ 边界。
