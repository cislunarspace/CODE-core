# 分类标签

skill 使用五种标准分类角色。本文件把这些角色映射到本仓库 issue 跟踪器实际使用的标签字符串。

| mattpocock/skills 中的标签 | 我们跟踪器中的标签 | 含义 |
| -------------------------- | -------------------- | ---- |
| `needs-triage`             | `needs-triage`       | 维护者需要评估该 issue |
| `needs-info`               | `needs-info`         | 等待报告者补充信息 |
| `ready-for-agent`          | `ready-for-agent`    | 已充分定义，可交给无人值守 agent 执行 |
| `ready-for-human`          | `ready-for-human`    | 需要人工实现/判断 |
| `wontfix`                  | `wontfix`            | 不处理 |

当 skill 提到某个角色（例如“应用 AFK-ready 分类标签”）时，请使用上表右列对应的标签字符串。

如需适配不同词汇，编辑右列即可。
