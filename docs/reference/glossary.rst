CR3BP 相关术语
---------------

.. glossary::

   CR3BP
      圆型限制性三体问题 (Circular Restricted Three-Body Problem)

   质量参数
      μ = m₂/(m₁+m₂)，较小天体质量与总质量之比

   拉格朗日点
      旋转坐标系中的五个平衡点 (L1-L5)

   Jacobi 常数
      CR3BP 中唯一的运动积分

   halo 轨道
      围绕拉格朗日点的周期轨道

   状态转移矩阵
      描述轨道扰动传播的矩阵 (STM)

   微分修正
      通过迭代修正初始条件求解周期轨道

   延拓法
      从已知解追踪轨道族的方法
