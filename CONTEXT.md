# Context: e2m2e

Earth to Moon, Moon to Earth — A Python library for designing cislunar transfer orbits using CR3BP dynamics.

## Domain Glossary

### Core concepts

**CR3BP** — Circular Restricted Three-Body Problem. The foundational dynamical model: two massive bodies (e.g., Earth-Moon) in circular orbit, with a massless third body (spacecraft). Units are dimensionless (DU, TU, VU).

**Orbit** — A periodic or quasi-periodic trajectory in the CR3BP. Stored as `(n_points, 6)` state vectors `[x, y, z, vx, vy, vz]`.

**State vector** — Six-element array `[x, y, z, vx, vy, vz]`. Position in DU, velocity in VU. **Always use this order.**

**STM** — State Transition Matrix. Shape `(n_points, 6, 6)`. Maps perturbations in initial state to perturbations at a later time.

**Jacobi Constant** — Energy-like conserved quantity in CR3BP. Used to characterize orbit families and for initial guess selection.

### Equilibrium points

**L1, L2, L3** — Collinear Lagrange points. L1 between the two primaries, L2 beyond the smaller body, L3 opposite.

**L4, L5** — Triangular Lagrange points. 60° ahead/behind the smaller body in its orbit.

### Orbit families

**Southern/Northern** — Vertical Lyapunov orbits on the southern/northern side of the Lagrange points.

**Halo** — Three-dimensional periodic orbits around collinear Lagrange points. Defined by a "type" (northern/southern) and an "amplitude" (z-extent). Initial guesses generated by strategy functions in `algorithms/strategies/halo.py`.

**Vertical** — Orbits perpendicular to the orbital plane.

**Planar** — Orbits lying in the plane of the two primaries.

### Algorithms

**Differential Correction** — Iterative algorithm to refine an initial guess into a precise periodic orbit. Varies x0, y0, or t0 until the state at period-return matches the initial state.

**Continuation** — Path-following technique to generate families of orbits as a parameter (e.g., Jacobi constant) varies. Maintains periodicity constraint through the family.

**Stability Analysis** — Computes the eigenvalue spectrum of the monodromy matrix (STM at one period) to classify orbit stability.

**Multiple Shooting** — Splits a long trajectory into segments, adds state variables at intermediate nodes, and solves a boundary value problem. Reduces sensitivity to integration errors.

**Two-Level Multiple Shooting** — A multiple shooting correction that alternates two Newton levels: level 1 enforces position continuity by adjusting segment departure velocities, and level 2 reduces velocity discontinuities by adjusting internal patch-point positions and epochs. Public APIs use patch states shaped `(n_points, 6)`.

### Transfer design

**Transfer** — A trajectory that moves a spacecraft from one orbit to another. May be impulsive (instantaneous velocity change) or low-thrust.

**Grid Search** — Exhaustive search over departure/arrival conditions on departure and arrival orbit families.

**NLP Optimization** — Nonlinear programming (via COPT or SciPy) to minimize transfer cost (e.g., total Δv) subject to constraints.

### MBSE infrastructure

**Pydantic Model** — Data validation model. Core models: PropagationResult, OrbitProperties, OrbitStability, JacobiResult.

**Requirement** — A system requirement tracked via RequirementRegistry. Has ID, text, status, and links to verifying components.

**Mermaid Diagram** — Auto-generated from MBSE data. Types: BDD, IBD, state machine, activity, sequence, requirement.

## Critical conventions

| Convention | Rule |
|------------|------|
| State vector order | `[x, y, z, vx, vy, vz]` — never change |
| States shape | `(n_points, 6)` — not `(6, n_points)` |
| STM shape | `(n_points, 6, 6)` |
| Numerical tolerance | `rtol=atol=1e-12` always |
| Units | Dimensionless (DU, TU, VU) — call `set_characteristic_scales()` for physical values |
| Reference epoch | `"2025-06-21T11:00:06"` for SPICE operations |

## Avoided terms

These synonyms are deprecated — use the terms above:

| Don't use | Use instead |
|-----------|-------------|
| "state" (ambiguous) | "state vector" or "system state" |
| "LPO" | specific family name (halo, vertical, etc.) |
| "jacobi" (lowercase) | "Jacobi" (capitalized) |
| "CR3BP" variant spellings | "CR3BP" exactly |
