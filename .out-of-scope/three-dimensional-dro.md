# 三维 DRO 族（平面 DRO 族的面外分岔支）

e2m2e 不实现「从平面 DRO 族垂直临界点生成三维 DRO 族」：在 DE421 地月 CR3BP 下该族的垂直临界点不存在，三维 DRO 周期族没有可生长点。

## 为什么不在范围内

**前提在物理上不成立，不是优先级问题。** #689 的标定（脚本 `scripts/calibrate_dro3d_vertical_critical.py`，随 PR #704 入库）沿平面 DRO 族跟踪 monodromy 的 z-vz 块稳定性指标：199 成员覆盖振幅 3 074–393 068 km，候选穿越 0、跳支区间 0、失败点 0；`vt`（z-vz 块半迹，与稳定性指数满足 `ν_out = 2·vt`）全程 < 1 且两端单调趋近 `1⁻`（增大侧 0.1543 → 0.999188，减小侧 → 0.999727）。

两条独立于扫描器的证据支撑同一结论：

- **解析极限**：近月端成员近似月心 Kepler 逆行轨道，`vt = cos(2π·T_syn/T_k)`，逆行同步条件给出 `T_syn/T_k = T_moon/(T_moon + T_k) < 1`，故 `r → 0` 时 `vt → 1⁻`；在振幅 10/15/20 千 km 处模型值与实测一致到 0.3%；
- **两端探针**：近月端（振幅 803 km）`1 − vt = 1.5e-5`，大振幅端（384 399 km ≈ 地月距离）`1 − vt = 4.3e-6`，两端趋近而不穿越。

面内 `ν ∈ [−1.53, +0.65]`、面外 `ν ∈ (0.16, 2)` 全程线性稳定，无鞍结／倍周期／环面穿越 ⇒ 不存在该族的三维周期分岔支。以固定 `z0` 做三维修正的实测要么不收敛，要么收敛到 `z(t) ≈ z0` 的退化解，与「三维周期解只在面外线性临界点邻域分岔出现」一致。

**不是本仓库的实现缺陷**：不存在的对象无法"实现"。公开文献中的三维 DRO 类构型通常出现在更完整的力模型（第三体摄动、月球轨道偏心率）下，或作为平面 DRO 邻域的拟周期不变环面——后者亦已拒绝（见 `.out-of-scope/invariant-torus-qpit.md`）。

## 复核路径

本决定由维护者裁定（#689，2026-09-26，裁决 (b)：前提不成立，关闭）。定位变化时按以下路径复议：

- 更换 μ／力模型／另寻分岔点：需另开 issue 并自证前提；标定脚本与穿越判据口径已随 PR #704 入库，可直接复用；
- 本记录只覆盖 DE421 地月 CR3BP，不得据此断言其他 μ 下不存在三维 DRO 族；
- 相关但不相同：`classify_orbit` 对空间月心轨道缺少标签路径（#707），与「是否存在三维 DRO 族」无关，独立处理；
- 验证纪律：ADR 0013 按物理定义验收；`.out-of-scope/qiao-normal-form-regression.md` 禁止以 qiao 中间结果作 oracle。
